# User Manual

The sections of the **ICON User Manual** are:

[](ref_buildrun_building_intro)
: Extensive documentation of ICON's build system. Learn how to configure ICON to build the desired components of ICON on your platform.

[](ref_buildrun_input_data)
: Learn about the input data which is needed to perform an ICON simulation, from constant data like grid files or external parameter files to time dependent like initial or lateral boundary data.

[](ref_buildrun_running)
: Learn how to run the ICON model.

[](ref_buildrun_supportedconf)
: List of supported configurations, including example input data which can be used to perform first simulations.

[Namelist Overview](ref_buildrun_nml)
: Description of the available namelist options in ICON.

[](ref_buildrun_environments)
: Information on supported enviroments.

[](ref_buildrun_faq)
: Collection of frequently asked questions.
